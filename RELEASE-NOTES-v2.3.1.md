## Item Repair Hub v2.3.1

By DaggerHashimoto. Renewal only. This is the working standalone starter version previously shared on Discord, now released from its public source.

- Open **Item Repairs** in game to manage your collection.
- Add optional manual-use skills and attack autocasts to weapons/armor.
- Adjust class-family access and transfer rules; consumables have transfer controls only.
- Includes Agni Sword, Cocytus Armor and All-in-One Buff Potion examples.
- Optional World Sync Extras v2.1.5 compatibility hides overlapping class/transfer controls while retaining Skills.
- 1,107 selectable player skills; unavailable/reference skills stay disabled.

**Download `ItemRepairHub-v2.3.1.zip` below.** Extract the item-repair-hub folder into state/mods (or import using the app), enable, then Apply & restart and reopen the game client.

**Custom changes still require Save & Export and manual folder replacement.** Registry updates replace generated repairs; back up your collection first, reopen the new editor and re-export the saved draft. Preserve the app-created .source.json when installing personalized exports to keep update tracking. See the repository README for the full update procedure and limitations.

Package checked with official app 1.7.4 on Windows; bundled definitions are from 1.7.0. Manual skill grants can conflict with other item-script mods. No custom app integration is needed. Find Mods availability requires the upstream registry listing to be accepted.
